# p2b (Prisma to Bun)

Generate [Bun](https://bun.uptrace.dev/) models from a [Prisma](https://www.prisma.io/) schema.

## Requirements

- Go 1.26 or newer
- Prisma CLI
- A Go module containing the generated models and the `github.com/uptrace/bun` dependency

## Usage

Add `p2b` to the `generator` block in `prisma/schema.prisma`:

```prisma
generator bun {
	provider = "go run github.com/dundunlabs/p2b"
	output   = "../model"
}
```

Run Prisma generation from the project directory:

```sh
go get github.com/uptrace/bun
```

The generator writes `models_gen.go` to the configured output directory. For the example above:

```sh
npx prisma generate
```

The generated package includes:

- Bun model structs with table and column mappings
- Go enums for Prisma enums
- Basic Prisma scalar types, nullable fields, and list fields
- `has-many` and `belongs-to` relation metadata

Generated files begin with `Code generated by P2B. DO NOT EDIT.` Re-run `prisma generate` after changing the Prisma schema.

## Development

Run the tests with:

```sh
go test ./...
```
